# Simplified Chinese card font

`Yu-Gi-Oh-DFKaiW5-A-SC.ttf` was supplied by the project owner for the
non-commercial, fan-made Simplified Chinese OCG card workflow.

- Embedded family: `Yu-Gi-Oh! DFKaiW5-A`
- SHA-256 of the supplied source file:
  `E0BF94B8BDBF5B90CB25EDB2AFB045B0DD7B8D9E0608DBC6B3DE3B7507363F5D`
- Intended use: card name, effect text, Pendulum effect text, and type/ability
  line for `format: "ocg"` + `region: "ch"`

The font is a community-modified DIY resource with unclear upstream font
provenance. Do not assume that it is licensed for commercial use or unrelated
redistribution.
